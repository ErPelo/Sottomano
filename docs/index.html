Sottomano

Gli strumenti che ti servono sui file, a portata di mano. Gratis e open source, per Windows 10 e 11.

Installa o aggiorna con un comando

Apri PowerShell (Start, scrivi PowerShell, Invio) e incolla:

irm erpelo.github.io/Sottomano | iex

Oppure, dal Prompt dei comandi (cmd):

cd /d %TEMP% && curl -L -o sottomano.zip https://github.com/ErPelo/Sottomano/archive/refs/heads/main.zip && tar -xf sottomano.zip && Sottomano-main\installa.bat

Il comando scarica l'ultima versione da GitHub e avvia installa.bat: lo stesso comando serve sia per installare sia per aggiornare. Questa pagina è anche lo script che PowerShell esegue: puoi leggerlo qui.
